# Literary Translation Review

A Codex skill for source-grounded, book-length literary translation review and source-first retranslation, with complete-book understanding, character dialogue evidence, cross-volume wording consistency, annotated EPUB editions, and transparent critical commentary.

这是一套可复用审校流程，不是全自动翻译软件，也不附带任何小说语料、模型账号或API服务。模型和供应商可配置；没有对特定模型的文学质量作保证。

## 使用

将本仓库复制到 Codex 的技能目录下，文件夹名为 `literary-translation-review`。在任务中使用 `$literary-translation-review`，并提供合法可用的原文、现有译稿、历史参考、期望交付范围及成本约束。

入口为 [SKILL.md](SKILL.md)。详细资料规范和读者版结构在 `references/`，可填写模板在 `assets/`。不要将私有书稿提交到此仓库。

## 无需模型的示例检查

需要 Python 3.10 或更新版本，无第三方依赖：

```sh
python scripts/check_manifest.py assets/review-manifest.example.json
python -m unittest discover -s tests -v
```

校验器检查申报的段落、注释与改后复查覆盖关系，不读取小说正文，也不证明语义、文风或设备适配正确。真实工程还需源文件绑定、实际读回和文学审校。

## 实际审校案例：《鸟物语》

以下是一次私人读者版审校中的少量用例，不提供小说全文。例句与名称的作品权利归原权利人，不能由本仓库的 MIT 许可授权使用；所参中文稿的译法也不等同于官方定译。

| 问题 | 最终处理与依据 |
| --- | --- |
| 能力名与动作 | “依照「多数例外规则」出招”：原文的“遵循”呼应能力名中的“规则”，补明出招动作，让双关和动作都能读懂。 |
| 姓名在版本融合时回退 | 按所参《接物语》第006节恢复“迪斯托比亚·维托索·殊杀尊主”，并一并核对简称“迪斯托比亚”“殊杀尊主”。最终正文仍须扫描，词表正确不代表成品正确。 |
| 三连称号 | “铁血的，热血的，冷血的吸血鬼”：按用户最终确认采用三连排比，保留原词序；同步替换旧句式裁定，避免词表把成品改回去。 |
| 月火的口头禅 | 历史对应采用“白金火大”。本卷没有找到对应日文源形，因而不把普通的生气描写改成该句。确认某人会说，不等于这句就在本段出现。 |
| 怪异名与泛称 | “死出之鸟”与“不死鸟”分别处理。《伪物语（下）》〈月火凤凰〉第010节解释前者的名称；不能仅因后者更常见就抹掉区别。 |
| 叙述与招牌口吻 | “面无表情、语调毫无起伏”是此处叙述的说话方式，不能凭人物印象补成“装可爱”的固定句。 |

这些案例展示的是有出处的局部决定。它们不能证明全书每一段已获人工文学终审，也不证明历史资料库已全部读完。译注应解释词义、笑点和必要背景，引用用书名、节号与场景定位；图片除核查是否打包，还要检查读者实际看见的尺寸。

## 后续读者反馈带来的补正

- 术语改用已有中文报道采用的“反不劳而获效应”（contrafreeloading），而非自行拼出的“反免费取食效应”；已有用法不等于唯一规范定译。
- 篇名采用“余接再烘焙”，在注释中保留 rebake 的字面意义和解释边界。
- 英文预告按源图保留 `TO BE CONTINUED` 与 `TUBASA PHOENIX`，不擅改拼写；片假名转写不冒称原稿英文。
- 新增译注须重新编排显示编号并复用上标样式，不能只确认链接可用。
- 卷末理解总结说明其辅助 AI 翻译的用途及局限。
