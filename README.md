# Literary Translation Review

A Codex skill for source-grounded, book-length literary translation review and source-first retranslation, with complete-book understanding, character dialogue evidence, cross-volume wording consistency, annotated EPUB editions, and transparent critical commentary.

这是一套可复用审校流程，不是全自动翻译软件，也不附带小说全文、私有语料库、模型账号或API服务。模型和供应商可配置；没有对特定模型的文学质量作保证。

## 使用

将本仓库复制到 Codex 的技能目录下，文件夹名为 `literary-translation-review`。在任务中使用 `$literary-translation-review`，并提供合法可用的原文、现有译稿、历史参考、期望交付范围及成本约束。

入口为 [SKILL.md](SKILL.md)。详细资料规范和读者版结构在 `references/`，可填写模板在 `assets/`。不要将私有书稿提交到此仓库。

## 无需模型的示例检查

需要 Python 3.10 或更新版本，无第三方依赖：

```sh
python scripts/check_manifest.py assets/review-manifest.example.json
python -m unittest discover -s tests -v
```

校验器检查申报的段落、注释与改后复查覆盖关系，不读取小说正文，也不证明语义、文风或设备适配正确。真实工程还需源文件绑定、实际读回和文学审校。

## 翻译与译注实例：《鸟物语》

下面选自《鸟物语》Astra AI 翻译私人读者版，展示人物口吻、前后照应和译注的具体处理。节号沿用书中正文编号。短摘录的作品权利归原权利人，不纳入本仓库 MIT 许可；所参旧译也不等于官方定译。

### 让人物身份自然地进入笑话

第001节，余接谈起走访旧识：

> 这样的行程，与其说像同学会，大概更像一场法事；但也正因如此，才称得上是最适合我这个尸体人偶的任务。

“同学会”先把重逢写得亲切，“法事”随即改变气氛，最后又被她一本正经地解释成适合自己的工作。笑点来自叙述者的身份和推理方式，不需要另加俏皮话。这类句子值得保留转折的次序，也不宜把末尾看似多余的自我解释删掉：余接的口吻恰好落在那里。

### 让一句短话承担人物转折

第023节，谈话触及余接如何看待自己的不幸：

> 一直不幸下去，是一种怠慢。

这里的力度在“一直”和“怠慢”：前者把目光放到持续的状态，后者突然给出判断。译文没有把它扩写成劝人振作的道理。同节的对白还具体谈到，不应因为自己是尸体、人偶或式神，就认定自己不该获得幸福。短句与后文分工，使人物关系中的劝告保有锋芒，也让余接对自身的定义成为读者能感受到的问题。

### 同一个词，要经得起整段故事的回看

第017节，前面用来比喻迂回处理事情的“寝技”，变成余接在柔道对抗中实际吃到的招数：

> 没想到我自己竟然会吃上一记并非比喻、而是货真价实的寝技。

到第030节，这段经历又被回收：

> 原本应该只是余兴，却成了不可或缺的伏笔。

这组例子展示的不是孤立的漂亮句子，而是跨场景用词的价值。如果把比喻处写成“迂回手段”、实战处另换术语，又不保留联系，读者就更难认出余接正在被自己先前的说法反将一军。审校因此要同时看比喻、动作和结尾照应，不能只判断某一处是否顺口。

### 译注补足中文无法同时保留的两次岔题

第001节，余接把吸血鬼相关事务称为“支线任务”，随即澄清不是“终结技”，又提到“招牌表情”。本版译注沿着这三步解释：

- 「サブミッション」在此既被拆作 sub-mission（旁支任务），又牵出 submission 的格斗含义，即使对手认输的降服技。
- 「極め技」与下一句「キメ顔」共享“きめ”的声音，再把话题从招式引向表情。

这比只注“这里是双关”更有用：读者能知道余接为什么突然澄清，又为什么接着说起表情。中文正文保留了岔题的行进顺序，声音上的连接则交给译注。它也有明确的限度——“终结技”并没有独自传达 submission 的全部格斗含义，不能把这组处理说成双关已无损移植。

### 解释笑点，也交代它为什么出现在这里

第004节的一条译注：

> 「腑抜ける」既可指没了心气，也让人联想到肚腹被掏空；下句借尸体人偶延续了这个冷笑话。

这条注释把词义和人物身体联系起来。若只解释成“失去斗志”，读者会明白情绪，却看不到下一句为什么转向尸体人偶。注释补的是两句话之间的联系，没有把解释塞进人物嘴里。

同节谈到影缝余割时，另一条译注把「割り切れる」的“能够整除”和“想得开、理清后接受”并列，说明数学名称“余割”又是人物姓名；此处谈的是余弦如何看待妹妹之死。这使词语游戏仍落在丧亲的语境里，不只剩下一条数学知识，也避免把双关错认到余接身上。

### 熟悉的称呼，应当接得上前作

这里涉及两位不同的吸血鬼，应分别核对姓名与称号：

- **迪斯托比亚·维托索·殊杀尊主**：姓名按所参《接物语》第006节采用。《鸟物语》第004节将其称作“决死的必死的万死的吸血鬼”，全名与简称“迪斯托比亚”“殊杀尊主”保持一致。
- **姬丝秀忒·雅赛萝拉莉昂·刃下心**：《鸟物语》第001、003节直接将其与“铁血的，热血的，冷血的吸血鬼”相连，第027节再次沿用这一称号。三连句式保留称号的节奏，不能移用于殊杀尊主。

名称、称号和对应人物应成组核对；只检索字符串是否一致，还不足以证明指代正确。这些是本版的有据选择，不宣称某个中文名字是唯一正确译法。

这些实例说明本流程希望保住什么：人物怎样绕着话说、一个词怎样在后文重新生效、注释怎样帮助读者接上笑点。它们是局部成品展示，不代表全书每段均已获得人工文学终审。
